PC 설치형 내려받기 (Windows)

설치 파일 (IUX-OCR-Setup.exe)약 110MB · 설치하면 바탕화면·시작 메뉴에 바로가기가 생깁니다 포터블 (IUX-OCR-portable.zip)약 155MB · 설치 없이 압축만 풀고 IUX OCR.exe 실행 · USB에 넣어 다니기
웹 버전과 다른 점
  1. 문서·이미지를 내 PC 폴더에 저장 → 수 GB 단위 대량 작업에 알맞음
  2. 폴더 일괄 처리(입력 폴더 → 결과 폴더), 검색 가능한 PDF, 정확 모드(PaddleOCR)·AI(Ollama) 추가 가능
  3. 파이썬·Tesseract(한국어) 포함 → 인터넷 없는 PC에서도 설치·사용
· 처음 실행할 때 Windows 보안 경고(SmartScreen)가 뜨면 추가 정보 → 실행을 누르세요. (서명 없는 프로그램이라 나오는 안내입니다)
· 실행하면 브라우저에 http://127.0.0.1:8765 화면이 열립니다. 검은 창을 닫으면 종료됩니다.
· 지난 버전·변경 내역: 릴리스 페이지

내 항목 템플릿

항목명 (엑셀 열 이름)찾는 방법설정값 변환여러 개현재 문서 결과
· 라벨 뒤 값: 문서에 '사업기간: ○○'처럼 이름표가 있을 때. 사업기간|기간처럼 |로 여러 표현을 적으면 먼저 찾은 것을 씁니다. OCR 띄어쓰기 오류(사 업 기 간)도 찾습니다.
· 형식: 날짜·기간·금액·전화·이메일·문서번호·사업자번호 등 모양으로 찾기. 여러 개를 켜면 모두 모읍니다.
· 정규식: 괄호( ) 안 부분이 값이 됩니다. · AI가 찾기: 이름표가 없는 내용(예: 사업 목적, 요청 사항). Ollama 필요.

시스템 입력 도우미

업무 시스템(웹) 화면 위에 작은 창을 띄워 항목 값을 입력 칸에 바로 채웁니다. 시스템을 고치거나 따로 프로그램을 설치하지 않습니다.

1. 설치 (한 번만)
⤓ IUX 입력 도우미← 이 버튼을 브라우저 북마크바로 끌어다 놓기
끌어놓기가 안 되면: 북마크 추가 → 이름 'IUX 입력 도우미' → URL 칸에 붙여넣기
2. 사용
  1. IUX OCR 항목 탭에서 값을 확인·수정
  2. 업무 시스템의 입력 화면에서 북마크 IUX 입력 도우미 클릭 → 오른쪽 위에 도우미 창
  3. 처음 한 번: '순서대로 지정'을 누르고 시스템의 입력 칸을 항목 순서대로 클릭 → 값이 들어가고 칸 위치를 기억
  4. 다음 문서부터: '자동 채우기' 한 번 → 눈으로 확인 → 시스템에서 저장 → '확인 완료 → 다음 문서'
연습용 가상 등록 화면 열기
· 값은 이 PC의 IUX OCR에서만 가져오며, 설치 링크 안의 비밀 키가 있어야 읽을 수 있습니다.
· 도우미는 저장 버튼을 누르지 않습니다. 채운 내용을 확인한 뒤 직접 저장하세요.
· 선택 목록(예: 생산기관)은 글자가 같은 항목을 골라 줍니다. 날짜 형식이 다르면 항목 편집의 값 변환에서 맞추세요.
· 시스템 보안 설정으로 연결이 막히면 후 도우미 창에 붙여넣으면 됩니다.
· 기관 보안 정책상 북마클릿 사용이 허용되는지 담당자에게 먼저 확인하세요.
