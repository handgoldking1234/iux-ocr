# IUX OCR — 로컬 문서 OCR & 재가공 프로그램 기획서

작성일 2026-11-06 · v0.1 (MVP)

---

## 1. 한 줄 정의

**스캔 문서·공문서를 인터넷 없이 내 PC에서 텍스트로 바꾸고, 바로 정리·구조화·마스킹·요약까지 해서 원하는 파일로 내보내는 프로그램.**
일반 PC는 Tesseract(가벼움) → PaddleOCR(정확), GPU가 있으면 로컬 AI(Ollama 비전 모델)까지 같은 화면에서 골라 쓴다.

## 2. 왜 만드나 (문제)

| 현장 문제 | 내용 |
|---|---|
| 보안 | 공문서·기록물·개인정보 문서는 클라우드 OCR(클로바, 구글 등)에 올리기 어렵다. 기록물 DB구축 현장처럼 **오프라인 PC**가 기본인 곳도 많다. |
| 비용 | 고정확도 데스크톱 OCR(ABBYY)은 연 구독, 클라우드 OCR은 페이지당 종량제. 대량 기록물에는 부담. |
| 인식 후 작업 | 대부분의 OCR은 "글자만 뽑고 끝". 줄바꿈 정리, 공문서 항목(문서번호·시행일자·수신·제목) 추출, 개인정보 가리기는 사람이 손으로 한다. |
| 검수 | 어느 글자가 틀렸을지 모른 채 전체를 다시 읽어야 한다. |

## 3. 경쟁사 분석

### 3-1. 비교표

|---|---|---|---|---|---|---|
| 클라우드 API | 네이버 CLOVA OCR | 클라우드 | 최상(97~99% 수준 보고) | 종량제 | 국내 최고 수준 인식률 | 외부 전송 필수, API 개발 필요, 텍스트+좌표만 반환(구조화는 직접) |

| 데스크톱 | 알PDF / 한컴 / UPDF | 로컬 | 중~상 | 무료~유료 | 익숙함, PDF 편집 겸용 | 한·영·숫자 혼합 문서 오류 후기, 재가공 기능 약함 |
| 무료 | 구글 드라이브·OneNote | 클라우드 | 중 | 무료 | 쉬움 | 보안·대량 처리 불가 |
| 오픈소스 엔진 | Tesseract 5 | 로컬 | 중 | 무료 | 어디서나 설치, 가벼움 | 한글 정확도 낮음, UI 없음 |
| 오픈소스 엔진 | PaddleOCR (korean PP-OCRv5) | 로컬(CPU 가능) | 상 | 무료 | 한국어 전용 모델, CPU로도 실사용 속도 | 설치 난이도, UI 없음 |
| 로컬 AI | Ollama + Qwen2.5-VL / Qwen3-VL / MiniCPM-V | 로컬(GPU 권장) | 상 | 무료 | 문맥 이해, 표·구조 인식, 재가공까지 | 무거움, 좌표 정보 없음, 가끔 내용을 '지어냄' |

### 3-2. 시사점

1. **"로컬 + 한국어 + 재가공"을 한 번에 하는 개인/소규모용 도구가 비어 있다.** 로컬은 ABBYY(비쌈, 재가공 없음), 재가공은 클라우드/기업 솔루션 쪽에만 있다.
2. **엔진은 이미 무료로 충분히 좋다.** PaddleOCR 한국어 v5 모델은 이전 세대 대비 오류율이 크게 줄었고 CPU로도 돌아간다. 차별점은 엔진이 아니라 **워크플로우(검수 → 재가공 → 내보내기)**.
3. **AI는 '선택'이어야 한다.** 일반 PC 현장(기록물 DB구축 등)은 GPU가 없다. 기본은 규칙 기반으로 완결되고, AI는 있으면 켜지는 구조.
4. **VLM OCR은 환각 위험** → 좌표 기반 엔진 결과를 기준으로 두고, AI는 '교정 제안'으로 비교 후 적용하게 한다.

## 4. 타깃 & 사용 시나리오

| 타깃 | 시나리오 |
|---|---|
| 기록물 DB구축·디지털화 현장 작업자 | 오프라인 PC에서 스캔 폴더를 통째로 일괄 OCR → TXT/검색가능 PDF로 저장 |
| 공공기관·학교 행정 | 종이 공문 스캔 → 문서번호·시행일자·수신·제목 자동 추출 → 엑셀 대장 |
| 개인정보 다루는 실무자 | 인식 텍스트에서 주민번호·전화·이메일 자동 마스킹 후 공유 |
| 일반 사무직 | PDF 스캔본 → 줄바꿈 정리된 깔끔한 텍스트/워드 |

## 5. 기능 정의 (MVP)

### 입력
- 이미지(JPG/PNG/TIFF/BMP/WEBP), PDF(여러 페이지) 드래그&드롭
- PDF에 이미 텍스트 레이어가 있으면 OCR 없이 바로 추출(빠름·정확)
- **폴더 일괄 처리**: 입력 폴더 → 출력 폴더, 진행률 표시

### 전처리 (일반 PC용, OpenCV)
- 기울기 자동 보정, 흑백화, 대비 향상(CLAHE), 노이즈 제거, 이진화, 저해상도 확대

### OCR 엔진 (자동 감지, 골라 쓰기)
| 모드 | 엔진 | 사양 | 특징 |
|---|---|---|---|
| 빠름 | Tesseract 5 (kor+eng) | 모든 PC | 줄 좌표·신뢰도 제공 |
| 정확 | PaddleOCR korean PP-OCRv5 | 일반 PC(CPU) | 한국어 인식률 우수, 좌표·신뢰도 |
| AI | Ollama 비전모델 (qwen2.5vl 등) | GPU 권장 | 문맥·표 인식, 좌표 없음 |

### 검수 화면
- 원본 이미지 위에 인식 박스 오버레이, **신뢰도 낮은 줄은 주황색 표시**
- 줄 클릭 ↔ 이미지 위치 동기화, 줄 단위 바로 수정
- 원본/전처리 이미지 전환, 확대·이동

### 재가공
| 일반(규칙 기반, 오프라인 즉시) | AI(로컬 LLM, 선택) |
|---|---|
| 줄바꿈·공백 정리(문단 복원) | OCR 오탈자 교정 |
| 공문서 항목 추출 → 표 | 요약 |
| 개인정보 마스킹(주민번호·전화·이메일·계좌) | 표 → 마크다운 표 정리 |
| 공문서 항목체계(1. 가. 1) 가))→개요 | 공문서 구조화(JSON) |
| 찾아 바꾸기 | 번역 / 직접 지시 |

모든 재가공은 **전/후 비교 → 적용** 방식 (원문 보존, 되돌리기).

### 내보내기
TXT · Markdown · Word(DOCX) · Excel(XLSX: 항목+줄별 신뢰도) · JSON(좌표 포함) · **검색 가능한 PDF**(Tesseract)

## 6. 시스템 구조

```
[브라우저 UI (단일 HTML, 오프라인)]
        │  http://127.0.0.1:8765
[로컬 서버 Python FastAPI]
   ├─ 전처리 (OpenCV)
   ├─ 엔진 어댑터: Tesseract │ PaddleOCR │ Ollama(VLM)
   ├─ 재가공: 규칙 엔진 │ Ollama(LLM)
   ├─ 내보내기: txt/md/docx/xlsx/json/pdf
   └─ 작업공간: workspace/ (문서별 이미지·결과 JSON 저장)
```

- 데이터는 PC 밖으로 나가지 않음 (서버는 127.0.0.1에만 바인딩)
- 화면은 CDN 없이 동작 (아이콘 인라인 SVG, 시스템 폰트)
- 엔진은 설치된 것만 자동 활성화 → 저사양 PC도 Tesseract만으로 완결
