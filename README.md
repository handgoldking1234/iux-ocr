# IUX OCR — 로컬 문서 OCR & 재가공

스캔 문서·공문서를 **인터넷 없이 내 PC에서** 텍스트로 바꾸고, 정리·항목 추출·개인정보 마스킹·AI 교정까지 한 화면에서 처리합니다.
서버는 `127.0.0.1`에서만 열리므로 문서가 PC 밖으로 나가지 않습니다.

기획·경쟁사 분석은 `docs/기획서.md` 참고.

## 세 가지 버전

| 버전 | 쓰는 법 | 할 수 있는 것 |
|---|---|---|
| **설치형 (권장)** | [Releases](https://github.com/handgoldking1234/iux-ocr/releases/latest)에서 `IUX-OCR-Setup.exe` 받아 설치 | 전체 기능. 파이썬·Tesseract(한국어) 포함, 인터넷 없이 설치 가능 |
| **포터블** | Releases의 `IUX-OCR-portable.zip` 압축 풀고 `IUX OCR.exe` 실행 | 설치형과 같음 (USB에 넣어 다님) |
| **웹** | https://ocr.iux.kr | 설치 없이 브라우저에서 빠름(Tesseract) 인식·항목·재가공·TXT/Word/Excel 저장. 문서는 서버로 전송되지 않고 그 브라우저에만 저장. 정확·AI 모드, 폴더 일괄 처리, 검색 PDF는 설치형 전용 |

- 설치형 exe는 `main`에 코드가 올라갈 때마다 GitHub Actions(윈도우)가 자동으로 빌드해 Releases에 올립니다.
- 웹버전은 `python tools/build_web.py`로 `app/static/index.html`에서 루트 `index.html`을 만들어 GitHub Pages로 배포합니다.
- 아래 1번(파이썬으로 직접 실행)은 개발용입니다.

## 1. 설치 (Windows, 처음 한 번)

1. **Python 3.10~3.12 (64bit)** 설치 — python.org, 설치 화면에서 *Add python.exe to PATH* 체크
2. **Tesseract** 설치 — "tesseract-ocr-w64-setup" (UB Mannheim 빌드)
   - 설치 중 *Additional language data* → **Korean** 체크
   - 기본 경로 `C:\Program Files\Tesseract-OCR`에 설치하면 자동 인식
3. `run_windows.bat` 더블클릭 → 첫 실행 때 필요한 패키지를 자동 설치하고 브라우저가 열립니다.

이후에는 `run_windows.bat`만 실행하면 됩니다. (검은 창을 닫으면 프로그램 종료)

macOS/Linux: `brew install tesseract tesseract-lang` 또는 `sudo apt install tesseract-ocr tesseract-ocr-kor` 후 `./run_mac_linux.sh`

### 인터넷이 없는 PC (기록물 현장 등)
1. 인터넷 되는 PC에서 `install\make_offline_bundle.bat` 실행 → `wheels` 폴더 생성
2. 프로그램 폴더 전체 + Python 설치 파일 + Tesseract 설치 파일을 USB로 옮김
3. 오프라인 PC에서 Python·Tesseract 설치 후 `run_windows.bat` → wheels로 자동 설치
   (두 PC의 Python 버전을 맞추세요)

포터블: Tesseract 폴더를 통째로 `bin\tesseract\`에 넣으면 설치 없이 사용합니다.

## 2. 엔진 고르기

| 버튼 | 엔진 | 필요 사양 | 특징 |
|---|---|---|---|
| **빠름** | Tesseract 5 | 모든 PC | 기본. 줄 위치·신뢰도 제공, 한글 띄어쓰기 자동 보정 |
| **정확** | PaddleOCR 한국어 PP-OCRv5 | 일반 PC(CPU) | 한글 인식률 높음. `install\install_paddleocr.bat`로 추가 설치 |
| **AI** | Ollama 비전 모델 | GPU 권장 | 흐린 문서·표에 강함. 위치 정보는 없음 |

AI 사용: ollama.com 에서 Ollama 설치 →
- 인식(비전): `ollama pull qwen2.5vl:7b` (가벼운 PC는 `qwen2.5vl:3b`)
- 재가공(텍스트): `ollama pull qwen2.5:7b` 또는 `gemma3:4b`

모델을 한 번 받아두면 인터넷 없이 동작합니다. 화면 상단 상태 표시를 누르면 설치 안내가 나옵니다.

정확도 높이기(Tesseract): `kor.traineddata` 고정밀판(tessdata_best)을 프로그램 폴더 `tessdata\`에 넣으면 우선 사용합니다.

## 3. 사용법

1. **파일 추가** — 이미지(JPG·PNG·TIFF 다중페이지·BMP·WEBP)나 PDF를 끌어다 놓기
   - 이미 글자가 들어 있는 PDF는 OCR 없이 바로 텍스트를 가져옵니다.
2. **인식** — `이 페이지 인식`(Ctrl+Enter) 또는 `전체 페이지 인식`
3. **검수** — 신뢰도 70 미만 줄은 **주황색**. 이미지의 박스를 누르면 해당 줄로 이동, 줄을 누르면 이미지 위치로 이동. 줄을 바로 고치면 자동 저장
4. **재가공** — 결과를 먼저 보여주고, `적용`을 눌러야 반영됩니다

| 일반 (오프라인 즉시) | AI (Ollama) |
|---|---|
| 줄바꿈·공백 정리 — 끊긴 문장을 문단으로 | 오탈자 교정 — 인식 오류만 수정 |
| 공문서 항목 추출 — 문서번호·시행일자·수신·제목·붙임·발신명의·기안자 등 | 요약 |
| 개인정보 마스킹 — 주민/외국인등록번호·전화·이메일·계좌·카드·여권 | 공문서 구조화(JSON) |
| 항목체계 → 개요 — 1. 가. 1) 가) ① □ ○ 를 마크다운 개요로 | 표 정리 / 쉬운 말로 / 영어 번역 / 직접 지시 |
| 찾아 바꾸기 (정규식 지원) | |

### 본문·내 항목 추출 (재가공 탭 맨 위)
- **본문 추출**: 기관명·수신·제목(머리)과 붙임·발신명의·결재란·연락처(꼬리)를 빼고 본문만 남깁니다.
- **내 항목 템플릿**: 원하는 항목을 직접 정의해 한 번에 뽑습니다. `항목 편집`에서 항목마다 찾는 방법을 고릅니다.

| 찾는 방법 | 예 |
|---|---|
| 공문서 항목 | 제목·문서번호·시행일자·수신·붙임·발신명의 등 자동 인식값 |
| 라벨 뒤 값 | `사업기간|기간` → "사업기간: 2026. 10. 26. ~ …"의 값 (OCR 띄어쓰기 오류도 찾음) |
| 형식 | 날짜·기간·금액·수량·전화·이메일·문서번호·사업자번호·홈페이지 (여러 개 모으기 가능) |
| 정규식 | 괄호 ( ) 부분이 값 |
| 본문 전체 | 본문 추출 결과 |
| AI가 찾기 | 이름표 없는 내용 (예: 요청 사항, 사업 목적) — Ollama 필요 |

  `현재 문서로 미리보기`로 결과를 보면서 고칠 수 있고, 예시 템플릿(기록물 메타데이터·계약서)이 들어 있습니다.
  선택한 템플릿은 Excel 내보내기의 첫 시트 '추출 항목'으로 들어가고, **폴더 일괄 처리**에서 고르면 파일마다 한 줄씩 모은 `항목추출_템플릿명.xlsx`가 만들어집니다.

### 항목 탭 — 문서별 입력값 (자동 채움 → 확인 → 시스템에 옮기기)
- 인식이 끝나면 선택한 템플릿 항목이 **자동으로 채워져** 문서별로 저장됩니다. 칸을 바로 고칠 수 있습니다.
- **개별 복사**(항목마다 복사 버튼) · **다음 항목**(Alt+C, 아직 안 복사한 항목을 차례로) · **전체 복사**(항목: 값) · **엑셀 한 줄**(탭 구분)
- **확인 완료 → 다음 문서**로 대량 문서를 차례로 처리. 문서 목록에 ✓ 확인 표시.
- 템플릿 편집의 **값 변환**: 날짜를 2026-11-06 / 20261106 / 2026.11.06으로, 숫자만, 한 줄로.

### 시스템 입력 도우미 (웹 업무 시스템에 바로 입력)
항목 탭 → `시스템 입력` → **IUX 입력 도우미** 버튼을 브라우저 북마크바로 끌어다 놓기.
업무 시스템 입력 화면에서 북마크를 누르면 작은 창이 뜹니다.
1. 처음 한 번: `순서대로 지정` → 시스템의 입력 칸을 항목 순서대로 클릭 (값이 들어가고 칸 위치를 기억, 프레임 안의 양식도 지원)
2. 다음 문서부터: `자동 채우기` → 눈으로 확인 → 시스템에서 직접 저장 → `확인 완료 → 다음 문서`
- 선택 목록(드롭다운)은 글자가 같은 항목을 골라 줍니다. 도우미는 저장 버튼을 누르지 않습니다.
- 연습: `http://127.0.0.1:8765/helper-demo` (가상 등록 화면)
- 값은 이 PC의 IUX OCR에서만, 설치 링크에 든 비밀 키로만 읽힙니다. 시스템 보안 설정으로 연결이 막히면 `도우미용 복사` → 도우미 창에 붙여넣기.
- 기관 보안 정책상 북마클릿 사용 가능 여부는 먼저 확인하세요.

5. **내보내기** — TXT · Word · Excel · **검색 가능한 PDF** · Markdown · JSON
   - 검색 PDF: 원본 이미지 위에 투명 글자층. 편집·마스킹한 텍스트가 반영됩니다(배경 이미지는 원본 그대로).
   - Excel: 줄별 결과(저신뢰 줄 주황색) + 공문서 항목 + 페이지 전체 3개 시트

### 폴더 일괄 처리
상단 `폴더 일괄 처리` → 입력·출력 폴더 지정 → 형식 선택 → 시작.
하위 폴더 구조를 그대로 유지해 저장하고, 끝나면 `OCR_처리보고서_날짜.csv`(파일별 페이지 수·평균 신뢰도·저신뢰 줄 수)를 남깁니다.
이미 결과가 있는 파일은 건너뛰므로 중간에 멈춰도 이어서 돌릴 수 있습니다.

## 4. 전처리 옵션

| 옵션 | 언제 |
|---|---|
| 기울기 보정 (기본 켬) | 비뚤게 스캔된 문서 |
| 대비 향상 (기본 켬) | 흐리거나 누런 종이 |
| 저해상도 확대 (기본 켬) | 200dpi 이하 스캔 |
| 노이즈 제거 | 점·얼룩이 많은 팩스·복사본 (느림) |
| 흑백화 | 배경이 고르지 않은 문서. 상태 좋은 문서엔 오히려 역효과 |
| 방향 감지 | 90°/180° 뒤집힌 페이지가 섞인 경우 |

페이지 분석 방식은 공문서라면 **문서(단일 단)**가 가장 정확합니다. 2단 신문·논문은 **자동 레이아웃**.

## 5. 폴더 구조

```
iux-ocr/
├─ run_windows.bat          실행 (윈도우)
├─ run_mac_linux.sh         실행 (맥/리눅스)
├─ requirements.txt
├─ install/                 PaddleOCR 설치, 오프라인 묶음 만들기
├─ app/
│  ├─ server.py             로컬 서버 (FastAPI)
│  ├─ engines.py            Tesseract / PaddleOCR / Ollama
│  ├─ preprocess.py         OpenCV 전처리
│  ├─ refine.py             규칙·AI 재가공
│  ├─ exporters.py          내보내기
│  └─ static/index.html     화면 (오프라인, CDN 없음)
├─ docs/기획서.md
└─ workspace/               작업 중인 문서 (자동 생성, 지워도 됨)
```

포트 변경: `run_windows.bat` 마지막 줄을 `python -m app.server --port 9000` 처럼 수정.
